---
description: Phase prompt — write a new plan for a piece of work (feature, bug-fix, refactor, ...)
argument-hint: <description of the work>
---
Write a plan for the following work, following the **Planning** rules in CLAUDE.md:

$ARGUMENTS

1. Investigate the relevant code. Do not change code yet. Read the project documentation in `docs/` (if any),
   especially anything on builds, code generation and packaging.
2. Run `node .claude/workflow/plan.mjs repos` (worktree names for `### <worktree>` headings) and read
   `.claude/workflow/commit-template.txt`.
3. Choose a short kebab-case slug and run `node .claude/workflow/plan.mjs new <slug> --title "<title>"`.
4. Fill in Brief, Outstanding Questions, Testing, Files Affected and Commit Messages, removing every
   `<!-- TODO -->`. Put every question for the human under Outstanding Questions (numbered, with options and your
   recommendation), not in the Brief; write `None.` if there are none. Files Affected includes the files the work
   will regenerate (lockfiles, generated code, migrations, snapshots, committed build output), noted
   `— generated by <command>`. If you can't tell whether a file is generated or committed, ask.
5. Run `node .claude/workflow/plan.mjs validate <slug>` until it passes. If it notes files shared with other
   plans, say so in the Brief (which plan, which files, how they interact).
6. Give the human a concise summary (approach, worktrees/files, commits, overlaps, open questions). Then stop:
   the human approves it in the UI.
