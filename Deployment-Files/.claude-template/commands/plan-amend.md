---
description: Phase prompt — amend a plan in planning with the human's instructions or answers
argument-hint: <plan> <instructions>
---
The human wants a plan amended: `$ARGUMENTS`
(the first word is the plan name, the rest is their instructions, often answers to questions you raised).

1. Run `node .claude/workflow/plan.mjs status <plan>`. It must be `planning`. Otherwise stop and say why:
   - `staged`: changing the plan mid-implementation is a deviation. The human can cancel it back to planning first.
   - `confirmation`: the human can send it back with feedback (rework) instead.
2. Read the plan in full. Apply the instructions following the **Planning** rules in CLAUDE.md:
   - Update the Brief, or the latest Plan Extension if there is one, and keep Testing, Files Affected and Commit
     Messages consistent with it.
   - Where the instructions answer a question in Outstanding Questions, record the decision in the Brief (or the
     latest Plan Extension) and remove the question. Add any new questions there; write `None.` when none remain.
   - Keep generated files in Files Affected (`— generated by <command>`) in step with the changes.
   - Edit only the plan body, never the front-matter.
3. Run `node .claude/workflow/plan.mjs validate <plan>` until it passes. If it reports files shared with other
   plans, address them in the Brief.
4. Summarise what changed and list the questions still in Outstanding Questions. Then stop: the human approves
   the plan in the UI.
