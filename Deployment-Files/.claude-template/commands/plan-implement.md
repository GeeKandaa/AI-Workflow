description: Phase prompt — implement a plan the human has staged
argument-hint: <plan>

Implement plan `$ARGUMENTS`.

1. Run `node .claude/workflow/plan.mjs status $ARGUMENTS`. If it is not `staged`, stop and tell the human it
   must be approved (staged) in the UI first.
2. Read `plans/$ARGUMENTS.md` in full and implement it, following the **Implementation** rules in CLAUDE.md:
   minor deviations → `plan.mjs note`; substantial deviations → `plan.mjs deviate` (alternatives as numbered options
   with your recommendation, in the deviate text itself), explain, and stop.
   Other plans may be in implementation in the same worktree: touch only the files this plan needs.
3. When finished, make sure Files Affected and Commit Messages describe what you actually did, then run
   `node .claude/workflow/plan.mjs complete $ARGUMENTS` and fix anything it reports. Files your work generated
   (builds, code generators, package managers, formatters) belong to this plan: add them to Files Affected as
   `— generated by <command>` and `note` them. Don't pass `--allow-unlisted` to get past them.
4. Summarise the changes and how to test them. Mention any generated file the plan (and `docs/`) didn't
   predict. Then stop: the human accepts, reworks or cancels in the UI.
